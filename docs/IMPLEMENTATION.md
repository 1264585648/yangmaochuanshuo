# DealDex 第一阶段实施记录

## 设计取舍

风格定义：**克制的奇幻卡牌质感**。采用木纹、皮革、旧金属、烫金徽章；避免大面积塑料高光、霓虹粒子、任务大厅和后台式多栏仪表盘。页面的焦点应是中央放大的卡包与「打开卡包」按钮。

视觉元素被分离为场景 SVG 与 CSS 可组合卡包，以便后续替换插画素材而不影响真实 HTML 文案、交互、SEO 与无障碍。

## 第一阶段功能

1. 四个卡包：切换时中心聚焦、周围降低亮度；点击可直接选中。
2. 开包：播放单次动效并获得 A / S / SSR 演示福利。
3. 记录：每天 3 次、图鉴去重展示、收藏；使用 localStorage。
4. 规则：统一展示演示概率；不将抽取与真实优惠领取混淆。
5. 响应式：桌面 1440×900 优先，兼容窄屏；可用键盘操作。

## 正式版前必须完成

- 服务端抽卡事务，防止重放、重复扣次与伪造结果
- 福利采集审核、有效期与库存状态、公示动态真实概率
- 领取资格条件（学生身份、地区、支付方式、账户新旧、自动续费）
- 真实福利详情与官方跳转链接，来源和最后核验日期
- 账号收藏同步与数据合规说明、错误/离线处理
- 真实浏览器交互与响应式视觉回归测试、性能与无障碍检查

## 非目标

首版不做支付、十连抽、皮肤商城、抽卡保底、任务体系、排行榜、账号系统、真实优惠发放。任何卡牌都不会在本站直接兑现第三方会员或赠金。
